# Beitragen zu EvoMentor - Deutsch

**Status:** Diese Datei ist der aktuelle, maßgebliche Beitragsprozess — es existiert derzeit kein
separates Governance-Dokument für dieses Repository. Da sich dieses Repository an
deutschsprachige Lehrkräfte und Mitwirkende richtet, ist diese Datei bewusst auf Deutsch
verfasst, anders als die meist englischsprachigen CONTRIBUTING-Dateien im übrigen OpenEvo-CCS-Lab-Ökosystem.

## Bevor Sie beginnen

Lesen Sie die [README](README.md) für einen Überblick über das Projekt und den aktuellen Stand
(derzeit eine App: Thüringen, Klassen 7–8, Biologie). Geplante Erweiterungen (weitere
Bundesländer, Klassenstufen, Fächer) sind in der README aufgeführt.

## Einen Beitrag vorschlagen

Öffnen Sie einen Pull Request mit einer Beschreibung der Änderung und deren Begründung. Vor dem
Merge ist die Freigabe durch eine:n Reviewer:in erforderlich — ein umfangreicherer Prozess
existiert für dieses Repository derzeit nicht. Für Ideen, Fehlerberichte oder Vorschläge öffnen
Sie bitte ein [Issue](https://github.com/openevo-ccs/EvoMentor_DE/issues).
